## Самостоятельные доработки (Повышенный уровень)
В ходе выполнения проекта были реализованы следующие элементы сверх базового задания:
1. **Собственная визуальная концепция:** Разработана уникальная фиолетовая цветовая палитра, изменены радиусы скругления и шрифты через CSS-переменные.
2. **Расширенный каталог:** Добавлено более 10 товаров, реализованы БЭМ-модификаторы (например, `product-card--hit`, `product-card--sale`).
3. **Фиксированный хедер:** Навигационная панель зафиксирована сверху (`position: sticky` / `fixed`).
4. **Фиксированная кнопка "Наверх":** Реализована с использованием `position: fixed`.
5. **FAQ-блок:** Реализован с использованием нативных HTML-тегов `<details>` и `<summary>` без использования JS.
